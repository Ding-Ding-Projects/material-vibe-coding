Documentation

Detailed feature documentation ships inside the app's built-in offline browser. Below are the key concepts.

Getting started

Download the installer from the Download tab. No additional dependencies needed. The app is unsigned under our permanent no-signing policy, so your OS may show a SmartScreen warning.

Editor

The code editor tracks lines and characters live. Use Ctrl+Shift+F for the command palette. The status bar shows Ln/Col position, character count, encoding, and language tag.

Converter

Browse categorized adapters, search by name or regex, and convert files locally without uploading them anywhere. Drag-and-drop is supported alongside the browse button.

Ollama models

If Ollama runs locally on port 11434, the Models panel detects it automatically on first visit and shows your available models. If not, it reports honestly rather than showing fake data.

Settings

Customize theme, language mode (English, Cantonese, or bilingual), independent English and Cantonese funny-level sliders, narrator voice, personal vocabulary JSON upload, and School mode.
