Getting started

Download and run the installer. No additional dependencies are needed.

Editor

The code editor tracks lines and characters live. Use Ctrl+Shift+F to open the command palette for quick navigation.

Converter

Browse categorized format adapters, search by name or regex, and convert files locally without uploading them anywhere.

Ollama models

If you have Ollama installed locally, the Models tab shows available models, their size, and hardware fit guidance.

Settings

Customize theme, language mode, per-language funny levels, narrator voice, School mode, and your personal vocabulary JSON file.
